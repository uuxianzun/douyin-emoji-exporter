# 抖音表情包导出工具

把抖音收藏的表情包批量导出到本地，自动转成**微信能直接发送**的格式（动态转 GIF、静态转 PNG）。
双击即用，无需预装任何环境。

## 功能与原理

### 功能

| 能力 | 说明 |
| --- | --- |
| 免安装 | 双击 `start.bat` 即可，不需要预装 Python |
| 勾选式导出 | 抓取后网格预览，支持点击勾选、拖拽框选、全选 / 反选 |
| 增量导出 | 已导出过的表情会标记出来，第二次可「仅选新增」 |
| 两种下载 | 「下载图片」逐张存成文件；「打包下载」压成一个 zip |
| 微信友好 | 动态 WebP 转高保真 GIF，静态图转 PNG |
| 登录持久化 | 扫码一次，之后打开免登录 |
| 一键清理 | 简单清理（留环境）或彻底清理（全部删空） |

### 工作原理

**① 表情地址是「限时凭证」，不是普通图片链接**

抖音的表情地址形如：

```
https://p3-im-emoticon-sign.byteimg.com/.../xxx.webp?x-expires=...&x-signature=...
```

`x-signature` 是与登录会话绑定的**临时签名**，脱离浏览器直接请求会返回 403。

所以工具不自己下载，而是**让浏览器去取**——在抖音页面内执行 `fetch()`，请求天然携带正确的 Cookie 与 Referer，服务器自然放行。

**② 因此必须在抓取瞬间就把原图存下来**

凭证会过期，「抓完慢慢挑」就来不及了。工具在**抓取的同时**立刻把原图缓存到本地（`data/cache/raw/`），之后无论何时勾选下载，读的都是本地文件，与网络彻底解耦。

> 缓存键按**图片本体**计算（剔除签名参数），因此同一张图只缓存一次、永久有效——这也是「签名过期、刷新又好了」这类问题被根治的原因。

**③ 格式转换要处理透明通道**

抖音存的是 WebP，而微信不认动态 WebP。转 GIF 时若不处理，透明区域会变成黑边。工具的解法：

- 单独提取透明通道做**掩模**，转换完成后把透明区域贴回；
- 颜色自适应量化到 255 色（留 1 个索引给透明）；
- 帧间用 `disposal=2` 防止残影；
- **静态图不转 GIF**，转 PNG 画质更好。

### 为什么不用纯协议方案？

签名算法（a_bogus 等）随抖音前端迭代而迅速失效，维护成本不可控。本项目选择**浏览器自动化**路线：需要手动登录一次，但稳定性最好、长期可用。

## 使用教程

### 运行环境

- Windows 系统
- **不需要预装 Python**，不需要任何环境配置

### 先分清两个窗口

| 窗口 | 是什么 | 你要做什么 |
| --- | --- | --- |
| **操作窗口** | 自动打开的 `http://127.0.0.1:8765` 网页 | 点按钮、看进度、勾选表情、下载 |
| **抖音窗口** | 点按钮后单独弹出的浏览器窗口 | 扫码登录、打开表情面板 |

> 简单说：**操作窗口管「下载」，抖音窗口管「操作抖音」**。两个窗口可以同时开着，来回切换即可。

### 第一步：启动

双击 `start.bat`，出现菜单后按回车（或等 10 秒自动开始）。

首次运行会自动下载便携式 Python、安装依赖、下载浏览器内核，需要几分钟；之后启动只需几秒。启动成功后会自动打开**操作窗口**。

| 菜单 | 作用 |
| --- | --- |
| `1` | 启动工具（默认） |
| `2` | 简单清理：清缓存和导出文件，保留环境 |
| `3` | 彻底清理：删除环境、依赖、浏览器内核，全部清空 |
| `0` | 退出 |

### 第二步：登录抖音

1. 在**操作窗口**点「打开抖音登录」，会依次弹出三步引导，按提示走完最后一步才会真正打开**抖音窗口**。
2. 在**抖音窗口**里用手机扫码登录。

### 第三步：打开收藏表情面板

在**抖音窗口**里依次操作：

1. 点左侧「消息」，进入任意一个私信
2. 点输入框旁的 **😊** 唤出表情菜单
3. 点击**收藏的表情（❤ 图标）**

> **⚠️ 关键：把表情列表滑到最底部，再点抓取！**
>
> 表情面板是**滚动加载**的——没滑到底，后面的表情根本没出现在页面上，工具就抓不到。
> 这是「抓取不全」最常见的原因。

### 第四步：抓取与下载

1. 回到**操作窗口**，点「开始抓取表情」（抓取时会自动滚动，通常几秒完成）。
2. 抓到的表情以网格显示，勾选你想要的：单击选中 / 取消，按住拖动框选，或用顶部按钮全选、反选、仅选新增。
3. 选择下载方式：
   - **下载图片**：逐张保存为单独文件、不打包，适合直接拖进微信发送。
   - **打包下载**：全部压成一个 zip，适合一次性拿很多张。
4. 浏览器会自动开始下载，同时 `output/` 目录也存了一份。

### 清理

用完想释放空间，在启动菜单选 `2` 或 `3`；服务停止后窗口也会再问一次。

| 档位 | 清掉什么 | 保留什么 |
| --- | --- | --- |
| 简单清理 | 缓存、导出文件 | 运行环境、依赖、内核、登录态 |
| 彻底清理 | 全部（含登录态） | 只剩程序代码 |

彻底清理需输入 `YES` 二次确认。若你电脑本就装有 Python，彻底清理**不会**去动它。

### 常见问题

**抓取到的表情不全？** 先确认表情面板已经滑到最底部，再点抓取。

**图片显示「签名已过期」？** 工具已做自动缓存与三重兜底，一般几秒内自愈；若仍有问题，刷新页面或重新抓取即可。

**下载多张时浏览器提示拦截？** 逐张下载会连续触发多个下载，选「允许」即可；不想被拦就改用「打包下载」。

**登录失效了？** 右上角状态标签显示「未登录」时，重新点「打开抖音登录」扫码即可。

**表情发到微信不动？** 工具已自动转 GIF；若原图本身是静态 WebP，则不会动。

## 文件结构

```
douyinbq/
├── start.bat                 启动脚本（双击这个）
├── run.py                    启动入口：环境引导、菜单、清理、拉起服务
├── requirements.txt          依赖清单
├── README.md                 说明文档（本文件）
└── app/
    ├── server.py             FastAPI 后端，提供接口
    ├── static/
    │   └── index.html        前端界面（单文件，含全部交互逻辑）
    └── core/
        ├── config.py         全局配置（路径、端口等）
        ├── scraper.py        Playwright 半自动登录与表情抓取
        ├── converter.py      WebP → GIF/PNG 高保真转换引擎
        └── downloader.py     并发下载、增量记录、zip 打包
```

运行后会自动生成以下目录，均不影响源码，可随时删除：

| 目录 | 内容 | 能否删除 |
| --- | --- | --- |
| `.runtime/` | 便携式 Python 运行时（约 140MB，仅在你电脑没有 Python 时下载） | 可删，下次启动自动重建 |
| `data/` | 登录态、原图缓存、下载记录 | 可删，但需重新扫码登录 |
| `output/` | 导出的表情文件 | 可删 |
